# Código del proyecto

Los módulos propios añadidos a GTA MANUCHO están en formato JavaScript legible dentro de `juego/`, especialmente:

- `juego/marine-world-v84.js`: natación, océano, seguridad de NPC/vehículos, barcos, islas, peces, tiburones y nubes.
- `juego/city-extras-loader.js`: carga ordenada de sistemas para reducir bloqueos.
- `juego/performance-boost.js`: optimizaciones del render.
- `project-credits.js`: metadatos y firma pública del proyecto.
- `startup-intro.js`: presentación aleatoria con imágenes y clips animados.

El archivo `juego/assets/index-CXrFrkSv.js` es la compilación completa del juego principal. Está incluido en el repositorio para que el proyecto funcione sin una fase de compilación adicional. Conserva las licencias de terceros incluidas dentro del propio archivo.
